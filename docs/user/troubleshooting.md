# トラブルシューティング

症状別の確認事項をまとめる。原因を詳しく調べるときは、設定ディレクトリ内 `logs\` の当日ログを確認する (通常は `%APPDATA%\ClipRefiner\logs\`、ポータブル時は `data\logs\`。[ログ](configuration.md#ログ))。異常終了 (パニック) もログに記録される。不具合報告時は該当する日付のログファイルを添付する。

## 起動・表示

| 症状 | 確認事項 |
| :--- | :--- |
| 起動してもウィンドウが出ない | 常駐モードは通知領域のみで動作する。隠れているアイコンも確認する |
| 設定・セレクターが開かない | WebView2 Runtime 未導入の可能性。起動時通知や表示失敗時の導入ページ案内に従い Evergreen Runtime を入れ、アプリを再起動する。手動導入は [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) |
| アイドル時のメモリ使用量が増える | セレクターは既定 `Keep` で非表示後も `WebView` を保持する。[セレクター WebView の保持](configuration.md#セレクター-webview-の保持-selector_webview_retention) で `DisposeOnHide` / `DisposeAfterIdle` に切り替える |

## 加工・監視

| 症状 | 確認事項 |
| :--- | :--- |
| 加工されない | トレイで一時停止・連続記録・監視方式・選択中のモード / 正規表現プリセットを確認する。パスワードマネージャー等が監視除外を指定したコピーは加工しない ([パスワードマネージャーの監視除外](security.md#パスワードマネージャーの監視除外)) |
| 「加工をスキップ」と通知される | 本文 2 MiB・パーサー 1 MiB・正規表現 2 秒のいずれかの上限。入力を小さくするかパターンを見直す。[処理の制限](configuration.md#処理の制限) を参照 |
| 大きなテキストや画像を処理できない | [処理の制限](configuration.md#処理の制限) のサイズ・件数上限を確認する |
| Event 監視でも反応が遅い | リスナ初期化失敗時は短周期 peek にフォールバックする。当日ログで `AddClipboardFormatListener` 関連の警告を確認する |

## 設定ファイル

| 症状 | 確認事項 |
| :--- | :--- |
| 起動時に設定の解析エラーが出る | `config.toml.bak` を開いて通知・ログに示された TOML 構文を修正し、アプリ終了後に `config.toml` として戻す |
| 未対応の設定 version と出る | 移行手順が無いスキーマ番号でも既存項目は維持される。ディスク上の `version` は自動では書き換えない。[設定ファイルの場所](configuration.md#設定ファイルの場所) を参照 |
| 未知キーの警告が出る | [設定項目](configuration.md#設定項目) と照合し、タイプミスや廃止済みキーを削除する。既知の設定は引き続き適用される。旧キー (`notify_mode` / `paste_queue` など) は警告対象外 |
| 外部編集が反映されない | エディタで保存した直後に反映される。構文エラー通知と当日ログを確認する。設定ウィンドウ表示中はバナーでも知らせる。ディレクトリ監視が失敗している場合は約 2 秒の周期確認になる ([外部編集の自動再読み込み](configuration.md#外部編集の自動再読み込み)) |
| 設定や登録クリップを保存できない | 設定ディレクトリ (通常は `%APPDATA%\ClipRefiner`、ポータブル時は `data\`) の書き込み権限、空き容量、セキュリティソフトのブロックを確認する |
| ポータブルなのに `%APPDATA%` を見ている | 実行ファイルと同じフォルダにファイル名ちょうど `portable` があるか確認する。`CLIP_REFINER_CONFIG_DIR` が優先されていないかも確認する ([ポータブルモード](configuration.md#ポータブルモード)) |

## ホットキー

| 症状 | 確認事項 |
| :--- | :--- |
| ホットキーが反応しない | 他アプリとの重複を避け、設定ウィンドウ「ショートカット」で割り当てを変更する |
| ホットキーが既定値へ戻る | [対応するキー形式](configuration.md#ホットキー形式) か、他の割り当てと重複していないか確認する。設定ウィンドウから保存した場合は補正内容がフィードバック表示される |
| OCR が `Alt+Shift+O` のまま / 効かない | 既定は `Alt+Shift+G`。既存の `hotkeys.ocr` が残っている場合はそちらが優先されるため、設定ウィンドウ「ショートカット」または `config.toml` で変更する |

## 連続記録

| 症状 | 確認事項 |
| :--- | :--- |
| `Ctrl+V` してもキューが減らない | 貼り付け取り出しは `Alt+Shift+X` (`hotkeys.continuous_record_paste`)。通常の `Ctrl+V` は OS に任せ、キューを消費しない |

## ワンショット

| 症状 | 確認事項 |
| :--- | :--- |
| ワンショットが常駐に委譲されない | 常駐未起動時はローカル実行する。常駐中にパイプへ届かない場合は二重加工を避けるためローカル実行せず失敗する。待受スレッド起動失敗時はデスクトップ通知する。[ワンショット IPC](security.md#ワンショット-ipc) と [信頼境界](security.md#信頼境界-同一ユーザー前提) を確認する |

## アプリの更新

| 症状 | 確認事項 |
| :--- | :--- |
| 更新確認が失敗する / 適用できない | ネットワークと当日ログを確認する。digest 欠落・SHA-256 / サイズ不一致・署名の欠落 / 検証失敗・不正なアセット名・アーキテクチャ不一致のアセットは適用しない。署名を検証しない旧版 (1.0 系まで) からの更新は、その 1 回だけ署名なしで適用される。ARM64 PC では `aarch64` 付きの MSI / ZIP がリリースに必要 (x64 版へはフォールバックしない)。認証に失敗した場合はキー埋め込みのない旧ビルドから保護範囲へ更新しようとしている可能性がある。[アプリの更新](usage.md#アプリの更新) を参照 |
| ポータブル更新後も古い版のまま | 差し替えヘルパー起動失敗時は展開先がエクスプローラーで開く。実行フォルダへ手動で上書きし、`portable` と `data\` を残したまま新しい `ClipRefiner.exe` を起動する |
