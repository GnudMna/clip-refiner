# 使い方

トレイ常駐 (監視モード)・ワンショット・各 UI の操作をまとめる。全体の案内は [はじめに](introduction.md)、`config.toml` のキーと既定値は [設定リファレンス](configuration.md)、保護の仕組みは [セキュリティ](security.md) を参照。

## 監視モード

トレイアイコンの右クリックメニュー、または [設定ウィンドウ](#設定ウィンドウ) から変換モード・正規表現プリセット・監視方式・履歴・連続記録などを操作する。

- **自動変換:** コピーのたびに変換するかどうか (`auto_refine_enabled`)。新規インストールでは無効で、クイックセレクターやお気に入りホットキーで手動変換だけを行う
  - 切り替え: トレイ「変換モード → 自動変換を有効にする」か、設定ウィンドウ「変換」タブで行う。トレイの変換モードやクイックセレクターの `Ctrl+Enter` でモードを選んでも有効になる
  - 状態の確認: トレイメニューの「変換モード」の表示 (`変換モード: URLデコード (自動変換オン)` など) と、トレイアイコンのツールチップ (`自動変換: URLデコード` / `自動変換: オフ`) に出る
  - 無効の間は監視による加工を行わないため、履歴にも記録されない
- **複数モードの連鎖:** `config.toml` の `pipeline` または設定ウィンドウ「変換」タブで指定する ([加工パイプライン](configuration.md#加工パイプライン-pipeline))
- **正規表現:** トレイ **正規表現プリセット** で有効プリセットを選び、変換モードで `regex-replace` などを選ぶ ([正規表現プリセット](#正規表現プリセット))
- **監視方式:** 既定は OS 通知で変更を受け取る `Event`。`Polling` は一定間隔 (既定 1 秒) で読み取る ([監視方式](configuration.md#監視方式-monitor_mode))

## ワンショットモード

```powershell
.\ClipRefiner.exe -m json-format
.\ClipRefiner.exe -m regex-replace --regex-pattern "(\d{4})-(\d{2})-(\d{2})" --regex-replacement "$1/$2/$3"
.\ClipRefiner.exe -m regex-replace --regex-preset 日付
```

- **正規表現オプション:** ワンショット時のみ有効。`--regex-preset` でプリセット名を選ぶか、`--regex-pattern` 等で一時的な 1 ステップ上書きができる。未指定の項目は `config.toml` の有効プリセットを使う
- **常駐中の実行:** トレイ常駐中は、常駐側へ加工を任せて二重加工を避ける。常駐が無ければそのまま実行し、常駐中に届かない場合は失敗する。仕組みと保護は [ワンショット IPC](security.md#ワンショット-ipc) を参照

常駐は多重起動できないが、ワンショットは常駐中も実行できる。

### コマンドラインオプション

| オプション                                      | 説明                                                    |
| :---------------------------------------------- | :------------------------------------------------------ |
| `-m`, `--mode <MODE>`                           | ワンショットで実行する変換モード                        |
| `--pipeline <MODE>...`                          | 順に適用するモード列 (`--mode` より優先)                |
| `--regex-preset <NAME>`                         | 正規表現プリセット名 (ワンショット時。表示名の先頭一致) |
| `--regex-pattern`, `--regex-replacement`        | 正規表現の 1 ステップ上書き (ワンショット時)            |
| `--regex-case-insensitive`, `--regex-multiline` | 正規表現フラグ                                          |
| `-h`, `--help` / `-V`, `--version`              | ヘルプ / バージョン                                     |

## システムトレイメニュー

トレイメニューには日常の操作だけを置く。監視方式・監視周期・通知・更新確認は [設定ウィンドウ](#設定ウィンドウ) で操作する。

| メニュー                     | 内容                                                                                                                                                                               |
| :--------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **変換モード**               | 自動変換で使うモードの選択と、自動変換の切り替え (詳細は下記) |
| **クイック変換…**            | [クイックセレクター](#クイックセレクター-altshifts) を開く (`Alt+Shift+S` と同じ)                                                                                                    |
| **登録クリップ**             | 登録済み文字列の呼び出し、クリップボードからの新規登録                                                                                                                             |
| **履歴**                     | 有効化・クリア、過去の加工結果の呼び出し                                                                                                                                           |
| **連続記録**                 | 有効化・クリア、記録済みテキストの取り出し (FIFO)                                                                                                                                  |
| **設定を開く**               | [設定ウィンドウ](#設定ウィンドウ) を表示                                                                                                                                           |
| **クリップボード監視を再開** | ワーカー初期化失敗などで監視が停止したときに手動復旧 (通常は無効)                                                                                                                  |
| **一時停止 / 終了**          | 監視の一時停止・再開、アプリ終了                                                                                                                                                   |

**変換モードメニュー:**

- メニュー名に現在のモードと自動変換の状態を表示する (例: `変換モード: URLデコード (自動変換オン)`)。連続記録中は `(連続記録中)`、パイプラインが 3 段以上なら先頭 2 段と残りの段数を表示する
- 先頭の「自動変換を有効にする」で、自動変換を切り替える
- カテゴリ別サブメニューからモードを選ぶと、自動変換も有効になる (2 段以上のパイプラインは解除して通知する)
- お気に入りの登録・解除・即切替ができる
- `pipeline` を設定しているときは、連鎖中の全モードにチェックを付ける
- 末尾の「正規表現プリセット」で、有効なプリセット (`regex.active_preset_id`) を選ぶ
- 連続記録が有効なときは、メニュー全体が無効になる

## 設定ウィンドウ

トレイ「設定を開く」で WebView ベースの設定ウィンドウを表示する。表示には [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) が必要。未導入の場合は起動時にデスクトップ通知で案内し、設定 / セレクターの表示失敗時は導入ページを既定ブラウザで開く (クリップボード監視・ホットキー・ワンショットは Runtime なしでも利用できる)。変更は少し待ってから自動で `config.toml` へ保存され、トレイメニューと監視へ即時反映される。ウィンドウを閉じる直前に保留中の変更は自動送信される (タイトルバーの閉じるボタン / ヘッダーの閉じる / `Esc` のいずれでも同様)。適用に失敗した場合はウィンドウ内にエラーを表示し、ウィンドウ非表示後もデスクトップ通知で伝える。ホットキーの不正・重複を補正して保存した場合は、どの割り当てを直したかを成功フィードバックで表示する。サイズと位置は設定ディレクトリ内の `settings-window.json` に保存される。

タブは、フォーカスがあるときに上下・左右の矢印キーと Home / End で移動できる。

ヘッダーの **config.toml** ボタン、または「ショートカット」タブから設定ファイルを既定エディタで開ける。ホットキー割り当ては設定ウィンドウの「ショートカット」タブで編集できる (`config.toml` の `[hotkeys]` でも同様に編集可能)。

| タブ               | 内容                                                                                                                                                        |
| :----------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **一般**           | 監視の一時停止・ログイン時の自動起動・バージョン表示・[更新確認 / 適用](#アプリの更新)。折りたたみの「詳細設定」に監視方式・監視周期 (100〜60000 ms の数値入力)・セレクター WebView 保持方針 |
| **変換**           | 自動変換の有効・無効、デフォルトモード、加工パイプラインの追加・並び替え・削除、お気に入り変換モードの追加・並び替え・削除 (最大 20 件)。連続記録 ON 時は自動変換の設定セクションを無効表示 |
| **正規表現**       | 名前付きプリセットとステップ一覧。有効化・並び替え・ライブプレビュー (選択中プリセットを順次 `regex-replace`) 付き                                           |
| **クリップボード** | 履歴・連続記録の有効化・保持件数・クリア (連続記録 ON 時はバナーで自動加工停止を表示)、登録クリップの一覧表示・コピー・削除・クリップボードからの新規登録 |
| **通知**           | マスター ON/OFF、加工完了・一時停止・履歴復元・OCR・登録クリップ・お気に入り・連続記録の個別トグル、クリップボード内容表示 (`notify_result`)                |
| **ショートカット** | グローバルホットキーの編集 (固定割り当て + お気に入りスロット。空欄でお気に入りスロットを無効化)                                                            |
| **情報**           | 同梱する利用者向けドキュメント (`docs\index.html`) と第三者ライセンス表示 (`THIRD_PARTY_NOTICES`) を既定のアプリで開くボタン。開発ビルドなど、実行ファイルのフォルダに無い場合は開けない |

**正規表現タブ:** プリセットの追加・並び替え・削除・有効化と、選択中プリセットのステップ編集ができる。構文チェックと置換プレビューは、本番と同じ正規表現エンジンで実行する。プレビューは選択中プリセットのステップを上から順に `regex-replace` で適用する。プレビュー用サンプル文字列は UI で任意に編集できる (初期値は `Hello world 123`。設定には保存しない)。コンパイルできないステップを含む設定は保存されない。履歴・連続記録・登録クリップの削除は確認ダイアログを表示する。

**変換タブのデフォルトモード:** `pipeline` が空のときは従来どおり監視で適用するモードを切り替える。`pipeline` が設定済みのときは `mode` のみ更新し、パイプライン自体は維持する (監視で適用されるのは `pipeline` の連鎖)。パイプラインをクリアすると、保存済みの `mode` が再び適用される。

## クイックセレクター (`Alt+Shift+S`)

コマンドパレット風 UI で変換モードを検索し、現在のクリップボードへ適用する。お気に入りが先頭に並び、自動変換が有効なときは使っているモードに「自動変換中」と表示する。

- **今回だけ変換:** `Enter` またはクリックで、現在のクリップボードへ選んだモードを一回だけ適用する。自動変換のモード・パイプラインは変わらない
- **自動変換に設定:** `Ctrl+Enter` または `Ctrl+クリック` で、選んだモードを自動変換モードに設定し (自動変換が無効なら有効にする)、現在のクリップボードにも適用する。2 段以上の加工パイプラインは解除し、その旨を通知する
- **カテゴリの開閉:** お気に入り以外のモードはカテゴリごとに折りたたんで表示し、見出しにモード数を出す。見出しの `Enter`・クリック・`→` で開き、`←` で閉じる (カテゴリ内のモード行で `←` を押すと見出しへ戻って閉じる)。開閉状態はアプリの起動中だけ保持し、再起動するとすべて閉じた状態に戻る。自動変換中のモードのカテゴリは表示時に開く
- **検索:** モード名・カテゴリ・CLI 名の部分一致 (ハイライト表示)。検索中はカテゴリの開閉にかかわらず一致したモードをすべて並べる
- **お気に入り:** 星印または `Ctrl+D` で登録・解除。`Ctrl+Shift+↑/↓` で並び替え
- **キー:** `↑/↓` 移動、`Enter` 今回だけ変換 (見出しでは開閉)、`Ctrl+Enter` 自動変換に設定、`←/→` カテゴリの開閉、`Esc` クリアまたは閉じる
- **WebView 保持:** [セレクター WebView の保持](configuration.md#セレクター-webview-の保持-selector_webview_retention) を参照

## 登録クリップセレクター (`Alt+Shift+T`)

登録したテキスト・画像を一覧し、選んだものをクリップボードへコピーする。ラベル・プレビューで検索でき、画像はサムネイルとホバープレビューで表示する。

- **登録:** トレイ「登録クリップ → クリップボードを登録」、またはセレクター内 `Ctrl+Enter` (画像優先)
- **上限:** 最大 100 件、ラベル 64 文字、テキスト 2 MiB、画像 PNG 16 MiB / 8192 px
- **キー:** `Enter` でコピー、`Del` で削除、`Ctrl+T` で[テンプレート](#登録クリップのテンプレート)の切り替え、`Esc` クリアまたは閉じる
- **並び替え:** 行の `▲` / `▼` または `Ctrl+Shift+↑/↓` で表示順を変える。検索中は並び替えできない。設定ウィンドウ「クリップボード」タブの一覧でも `↑` / `↓` で並び替えられる。順序はトレイの「登録クリップ」メニューにも反映される
- **WebView 保持:** [セレクター WebView の保持](configuration.md#セレクター-webview-の保持-selector_webview_retention) を参照

登録クリップは `registered-clips.dat` (暗号化) と `registered-images/` に保存される (`config.toml` には含まれない)。

### 登録クリップのテンプレート

テキストの登録クリップをテンプレートにすると、コピーするたびに本文中のプレースホルダを展開してからクリップボードへ載せる。日報の見出しや定型文に日付や今のクリップボードの内容を差し込む用途に使う。登録したままの本文は変わらない。

- **切り替え:** 登録クリップセレクターで行を選んで `Ctrl+T`、または設定ウィンドウ「クリップボード」タブの一覧で **テンプレート** ボタンを押す。テンプレートのクリップには「テンプレート」バッジを表示する。画像には使えない。登録直後は無効
- **展開の契機:** 登録クリップセレクター・トレイ「登録クリップ」・設定ウィンドウのコピーのいずれでも展開する
- **失敗時:** 書式指定が不正なとき、展開結果が 2 MiB を超えるときはクリップボードを変更せず、通知で理由を伝える

| プレースホルダ | 展開内容 (例) |
| :--- | :--- |
| `{date}` | コピー時の日付 (`2026-10-08`) |
| `{time}` | コピー時の時刻 (`09:05:03`) |
| `{datetime}` | コピー時の日時 (`2026-10-08 09:05:03`) |
| `{date:書式}` / `{time:書式}` / `{datetime:書式}` | 書式を指定した日時。書式は [chrono の strftime 形式](https://docs.rs/chrono/latest/chrono/format/strftime/index.html) (`{date:%Y/%m/%d}` → `2026/10/08`、`{time:%H時%M分}` → `09時05分`) |
| `{weekday}` | 曜日 (`木`) |
| `{clipboard}` | 展開直前のクリップボードのテキスト (テキストが無いときは空文字) |
| `{uuid}` | ランダムな UUID v4 (`{uuid}` ごとに別の値) |
| `{user}` | Windows のユーザー名 (環境変数 `USERNAME`) |

日時はローカルタイムゾーン基準で、1 回の展開の中では同じ時刻を使う。`{{` と `}}` はそれぞれ `{` と `}` になる。上の表に無い名前 (`{name}` など) や閉じていない `{` は書かれたまま残るため、JSON などの波括弧を含む本文もそのまま使える。

## 正規表現プリセット

- **有効化:** トレイ「変換モード → 正規表現プリセット」から有効プリセットを選択 (`regex.active_preset_id`)。連続記録 ON 時はメニューが無効化される
- **編集:** 設定ウィンドウ「正規表現」タブでプリセットの追加・並び替え・削除・有効化と、選択中プリセットのステップ編集ができる
- **適用:** トレイで選んだ操作 (`regex-replace` / `extract` / `delete` / `split`) が、有効プリセットの全ステップに同じ操作として上から順に適用される。パイプライン内の正規表現モードも同じ有効プリセットを参照する
- **ワンショット:** `--regex-preset` でプリセット名 (表示名の先頭一致) を選ぶか、`--regex-pattern` 等で一時的な 1 ステップ上書きができる。未指定の項目は有効プリセットを使用する
- **上限:** プリセット 20 件、各ステップ 10 件、パターン 8 KiB。マッチ実行時間は 2 秒、同時実行は 2 本

## お気に入り変換モード

- **登録:** トレイ「変換モード → お気に入り」、クイックセレクター `Ctrl+D`、または設定ウィンドウ「変換」タブ
- **上限:** 最大 20 件 (`favorite_modes` に永続化)
- **ホットキー:** 登録順に `Alt+Shift+1`〜`Alt+Shift+9` / `Alt+Shift+F1`〜`Alt+Shift+F11`。現在のクリップボードへ一回だけ適用し、自動変換のモード・パイプラインは変えない。`hotkeys.favorite_mode_slots` でカスタマイズ (空文字で無効)
- **トレイ:** 「変換モード → お気に入り」から選ぶと自動変換モードに設定する

```toml
favorite_modes = ["UrlDecode", "Trim", "JsonFormat"]

[hotkeys]
favorite_mode_slots = ["", "Alt+Ctrl+J"]  # 2 件目のみカスタム、1 件目は無効
```

## 履歴

トレイ「履歴 → 履歴機能を有効にする」または設定ウィンドウ「クリップボード」タブで有効化する (`history_enabled`、デフォルト無効)。加工結果を最大 `history_limit` 件 (1〜100、デフォルト 10) 保持し、同一内容は最新位置へ移動して重複しない。トレイ「履歴」から過去の加工結果をクリップボードへ復元できる。

履歴はディスクへ書かず、メモリ上で暗号化して保持する (プロセス終了で消える)。詳細は [履歴・連続記録の保護](security.md#履歴連続記録の保護) を参照。

## 連続記録

履歴とは独立した FIFO キュー。トレイ「連続記録 → 連続記録を有効にする」または `Alt+Shift+C` で有効化する (`continuous_record_enabled`、デフォルト無効)。監視時は加工を行わず、コピーした元テキストを専用キューの末尾へ追加する。

- **記録の開始:** 有効化時点で既にあるクリップボード内容は記録せず、以降のコピーから積む
- **上限:** 最大 `continuous_record_limit` 件 (1〜100、デフォルト 10)。上限超過時は先頭から破棄する。同一内容の再コピーでも重複排除せず積む
- **自動加工の停止:** 有効中はコピー監視による自動加工を行わない。トレイの「変換モード」「正規表現プリセット」メニューは無効化され、連続記録サブメニュー名は「連続記録 (自動加工停止)」、ツールチップは「ClipRefiner (連続記録中・自動加工停止)」になる
- **手動加工:** お気に入りホットキーやクイックセレクターなど、明示的な手動加工は有効中も動作する

| 操作                                   | 動作                                                                                                                                   |
| :------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------- |
| コピー (監視)                          | 元テキストをキュー末尾へ追加                                                                                                           |
| `Alt+Shift+X` 貼り付け                | キュー先頭をクリップボードへ載せてから通常の貼り付けを実行 (キューが空、または連続記録 OFF のときは現在のクリップボード内容を貼り付け) |
| トレイメニュー項目選択                 | 指定位置のエントリをクリップボードへ取り出し (除去)                                                                                    |
| 直近の取り消し (`Alt+Shift+Backspace`) | キュー末尾 (直近コピー) を 1 件削除。クリップボードは変更しない                                                                        |
| トレイ「記録をクリア」                 | キューを空にする                                                                                                                       |

```toml
continuous_record_enabled = true
continuous_record_limit = 10

[hotkeys]
continuous_record = "Alt+Shift+C"
continuous_record_undo = "Alt+Shift+Backspace"
continuous_record_paste = "Alt+Shift+X"
```

キューは履歴と同様にディスクへ書かず、メモリ上で暗号化して保持する ([セキュリティ](security.md#履歴連続記録の保護))。

## 加工の取り消し (`Alt+Shift+Z`)

監視モード常駐時、加工成功直後の直近 1 件のみ取り消し可能。ワンショット (`--mode`) では利用不可。新しい加工が成功すると対象は上書きされる。

## 画面 OCR

`Alt+Shift+G` で全画面オーバーレイを表示し、ドラッグで範囲選択。確定後にキャプチャと OCR を実行し、結果をクリップボードへ書き込む。`Esc` または再度ホットキーでキャンセル。

OCR エンジンは Windows 標準の `Windows.Media.Ocr` で、日本語を優先して使う (日本語が使えないときは、Windows のユーザー言語に合わせる)。キャプチャと認識は同時に 1 本だけ実行し、新しい範囲選択が始まると進行中ジョブの結果書き込み・通知は破棄する (エンジン自体の強制中断はできない)。

- **小さい選択範囲:** 短辺が小さい画像は自動拡大してから OCR
- **日本語の空白:** OCR が挿入する不要スペースを除去 (英単語間は維持)

## アプリの更新

設定ウィンドウ「一般」タブの「更新を確認」から最新リリースを調べる。起動時の自動チェックは行わない。配信は MSI / ポータブル ZIP のみを対象とする。

| 利用形態 | 適用手順 |
| :--- | :--- |
| **インストール版 (MSI)** | 新しい版があれば「ダウンロードして適用」で MSI を取得し `msiexec` を起動したあとアプリを終了する |
| **ポータブル** | ZIP を展開し、アプリを終了して実行フォルダへ上書きコピーしたあと、新しい版を起動する。`data\` は保持する。コピーが途中で失敗したときは更新前の状態に戻す。同梱の `docs\` などサブフォルダでは、新しい版で無くなったファイルを削除する。自動で差し替えられなかった場合は、展開先をエクスプローラーで開いて手動での差し替えを案内する |

更新確認・適用は同時に 1 本だけ実行できる。進行中に再実行すると「すでに実行中」と案内する。適用前の検証 (ハッシュ・署名・アーキテクチャ・ダウンロード認証) は [アプリ更新の検証](security.md#アプリ更新の検証) を参照。

## ログイン時の自動起動

設定ウィンドウ「一般」タブから切り替える。現在のユーザー向けレジストリ `Run` キーに登録し、`config.toml` には保存しない。

実行ファイルのパスが変わった場合 (再インストールや移動後など) は、一度オフにしてから再度オンにすると正しいパスで再登録される。ポータブルを USB で持ち歩く用途では、差し替えのたびにパスが変わりやすいため自動起動は向かない ([ポータブルモード](configuration.md#ポータブルモード) 参照)。
